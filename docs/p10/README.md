# Фаза P10 — пересчёт (инвентаризация)

Выборочный пересчёт склада: область — ячейки, группа номенклатуры, поставщик или весь склад.
Задание в разделе «ЗАДАНИЯ» на ТСД, подсчёт ячейки целиком, закрытие с корректировкой
остатка и Excel «Инвентаризация» для 1С. Штатный пересчёт расхождений в эксплуатации.
