## Сценарии

Тесты идут через настоящий роутер и очередь операций — так, как пересчёт проходят ТСД и портал:
старший смены заводит, кладовщик берёт ячейку, сканирует и шлёт факт операцией
`stocktake_cell_submit`, офис закрывает и забирает Excel.

- **Недостача, излишек, «не найдено»** (`TestStocktakeHTTP_shortageSurplusNotFound`). В первой
  ячейке 10 россыпью и короб с 6, во второй — 2 снека. Насчитано 7 и короб не найден; снеков 5 и
  4 лимонада сверх учёта. Проверяю: остаток приведён к факту сразу по ячейке, короб — на складе
  «Не найдено» проблемой `not_found`, видной на ТСД, три правки в `audit_log`; лист «Расхождения»
  — три строки, короб сложен с россыпью позиции (16 → 7) с пометкой «не найдено — проблема
  склада»; решение офиса «разместить» возвращает короб на «Основной».
- **Движение во время пересчёта** (`TestStocktakeHTTP_movementDuringCount`). Пока ячейку
  считают, `movement_submit` переносит из неё 2 единицы. Движение принято, ячейка `disrupted`;
  факт по старому снимку — отказ с русским текстом, который ТСД покажет дословно, остаток не
  тронут; повторный скан снимает свежий снимок (8), факт по нему проходит.
- **Досрочное закрытие** (`TestStocktakeHTTP_earlyClose`). Из двух ячеек посчитана одна:
  закрытие без подтверждения — 409, с `force` — `{"uncounted":1}`; остаток непосчитанной ячейки
  не тронут, в листе «Инвентаризация» она — строкой «не считалась»; ячейку закрытого пересчёта не
  взять.

Механику по слоям покрывают тесты прежних задач: снимок, область и триггеры — P10-02
(`repository/stocktake_integration_test.go`), подсчёт коробов и марок, отказы — P10-03
(`repository/stocktake_count_integration_test.go`), основной путь по HTTP и эталон формата ТСД —
P10-03/04 (`handler/stocktake_scenario_http_test.go`).

## Ключевые решения

- **Стартовые остатки — только проходом склада.** Импорта остатков из 1С для сверки план/факт
  нет: 1С не знает ячейку, короб и марку. Процедура — «Ввод остатков» по всем ячейкам при паузе
  движений, затем контрольный пересчёт «весь склад» вслепую и сверка итогов с 1С по документам.
- **Пересчёт не заводит неизвестное WMS**, поэтому стартовые остатки — «Вводом остатков»
  (свои короба с ярлыком, короба ЧЗ, марки), а пересчёт идёт вторым проходом как контроль.
- **Документ сводит короб с россыпью позиции** — тест фиксирует это как контракт для 1С: строка
  — ячейка, товар, партия, склад WMS.
