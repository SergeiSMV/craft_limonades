## Решения

- **Отказ от `http_mock_adapter` в пользу мини-фейка `test/support/fake_dio_adapter.dart`.** Планово закладывался `http_mock_adapter`, но на ответах 4xx/5xx он **не прикреплял `response`** к `DioException` — маппинг ошибок репозитория ломался (всё уходило в `NetworkFailure`). Свой `RecordingAdapter` (реализация `HttpClientAdapter`, ~40 строк) прикрепляет `response` корректно, записывает прошедшие запросы (для проверки заголовков повтора) и умеет эмулировать «нет сети» (билдер бросает `DioException`). Используется и в тесте интерсептора, и репозитория — один детерминированный механизм, минус одна зависимость.
- **Go — без testify:** хватает стандартного `testing`; go.mod не растёт.
- **Реальные примитивы в service-тестах:** `TokenManager` и argon2 берём настоящие (не моки) — проверяем сервис в связке с ними; мокаем только репозиторий (граница с БД).

### golangci-lint (важно для новичка)

`golangci-lint` — **не** стандартная команда Go и обычно **не установлена** в системе.
Если видите `zsh: command not found: golangci-lint` — это ожидаемо. Варианты:

1. **Ничего не делать.** Локальный линт **не обязателен**: его гоняет CI на каждом PR
   (workflow сам ставит `golangci-lint` install-скриптом на пиненую версию `v2.12.2` —
   см. `.github/workflows/ci.yml`, джоб `backend`). Достаточно, чтобы прошёл `go test`.

2. **Установить и запустить локально** (для само-проверки перед пушем):
   ```bash
   # установка той же версии, что в CI (кладётся в $(go env GOPATH)/bin, обычно ~/go/bin)
   go install github.com/golangci/golangci-lint/v2/cmd/golangci-lint@v2.12.2

   # запуск по полному пути (если ~/go/bin не в PATH)
   "$(go env GOPATH)/bin/golangci-lint" run ./...     # 0 issues
   ```
   Чтобы вызывать просто `golangci-lint`, добавьте `~/go/bin` в `PATH`
   (разово: `export PATH="$PATH:$(go env GOPATH)/bin"`; навсегда — строкой в `~/.zshrc`).

> **Итог:** для «зелёного» PR локально достаточно `flutter test` + `go test ./...`.
> Линт и сборку гарантирует CI — красный чек виден в PR и блокирует мерж
> (на приватном free-тарифе GitHub — самодисциплиной, см. `docs/p0-08.md`).

В CI (P0-08) тест-джобы теперь не вхолостую: `flutter` гоняет `flutter test`
(каталог `test/` появился), `backend` — `go test ./...`. Красный тест валит пайплайн.
