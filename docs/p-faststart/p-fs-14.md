# P-FS-14 · UX потока «Ввод остатков» (ТСД)

**Статус:** готово (ветка `p-fs-14-stock-entry-flow-ux`); ⚠ сквозной тест на DT50 ещё не прогонял.
**Фаза:** P-FastStart (доработка потока ввода остатков P-FS-07/11/12). Дизайн — неоморфный (см. [`architecture.md`](../architecture.md), «Визуальный стиль»).

## Задача

Доработать UX «Ввода остатков» по итогам живого теста на DT50: удобный выбор ячейки, коррекция
ошибочно выбранной ячейки, защита от случайной потери всего прохода, догрузка длинных списков.

## Что сделано

### Выбор ячейки — инлайн-автокомплит
- **`CatalogRepository.listAllCells({warehouseId})`** — грузит весь справочник ячеек склада целиком
  (пагинирует внутри по `maxLimit`=200 бэкенда, пока не наберёт `total`; ~700 ячеек — дёшево). Задел
  под offline-first (в P2 станет чтением из локального стора, сигнатура не меняется).
- **`CellSearchField`** (переиспользуемый) — неоморф-поле + `RawAutocomplete<Cell>` с **локальной
  prefix-фильтрацией** (`startsWith`, регистронезависимо; пустой ввод → списка нет). Скан полной строки
  + Enter резолвится точным совпадением локально (при пустом справочнике — серверный фоллбэк).
- Модалка `CellPickerSheet` и кнопка «выбрать из списка» удалены.
- **Фикс клавиатуры:** после сворачивания поле сохраняло фокус, и Flutter не переоткрывал клавиатуру по
  тапу — принудительный `SystemChannels.textInput 'TextInput.show'` при `focusNode.hasFocus`.

### Смена ячейки («не та ячейка», товары верны)
- **`StockEntryCubit.changeCell(newCell)`** — перецеливает буфер на новую ячейку, **строки сохраняются**;
  если новая ячейка уже пройдена — сливает количества по грани `(товар, дата)` (`_mergeLines`) и убирает
  её из пройденных (иначе на финале два чекпоинта на одну ячейку затёрли бы друг друга по SET-грани).
- **UI:** вся шапка адреса в `CellEntryView` (иконка + адрес + `edit_location`) — одна кликабельная
  область → `CellChangeSheet` (высокий лист со **встроенным** списком, не оверлей: в нижнем листе поле
  у низа, оверлею некуда развернуться; список появляется только при вводе, растёт вниз до половины
  свободной высоты) → `changeCell`, затем возврат фокуса скан-полю.

### Защита от потери прохода (вариант A — всё в памяти до финала)
- Единый перехват «назад» (стрелка в шапке и системный жест/кнопка) через **`PopScope(canPop: false)`**:
  - в ячейке → возврат к списку ячеек (`finishCell`, просчёт ячейки сохраняется), не выход;
  - на списке с непустым просчётом → диалог подтверждения выхода (иначе потеря);
  - пусто / после финала → штатный выход; во время финала (`busy`) — игнор.

### Прочее
- **`GoodPickerSheet`** (ручной выбор товара) — добавлена пагинация (грузил только первые 50): `_loadMore`
  от `offset=_goods.length`, слушатель скролла, футер-спиннер, поиск сбрасывает пагинацию.
- Шапки «Остатки»/«Ввод остатков» — фон-картинка (`AppbarImage`/`flexibleSpace`), светлый `PageHeader`;
  неоморф-доводки плиток ячеек/товаров и выпадашек; новые ассеты (`stock_entry.png`, иконки), убран
  временный `test_image.jpg`.
- i18n: `change_cell`, `cells_load_failed`, `discard_title/body/confirm`.

## Решения
- **Загружать весь справочник ячеек локально** (а не серверный поиск с дебаунсом): датасет мал (~700),
  фильтрация мгновенна, один запрос при открытии, и это прямой предшественник offline-first (P2).
- **Prefix-фильтр** ячеек — адреса всегда с буквы зоны (`M1-1-2-3`), «содержит» давало бы шум.
- **«Назад» в ячейке = `finishCell`** — рефлекторный тап делает ожидаемое (к списку, без потери);
  порядок пройденных ячеек оставлен «новейшее сверху» (хронология «где я только что был» ценнее).
- **Durability прохода** (не терять при краше/убийстве приложения) — вне объёма, это **P2** (Outbox/
  локальный стор). Здесь только интерим-предохранитель от случайного выхода.
