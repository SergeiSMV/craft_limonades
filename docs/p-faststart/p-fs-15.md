# P-FS-15 · Дизайн карточки остатков товара (ТСД)

**Статус:** готово (ветка `p-fs-15-stock-detail-ux`); ⚠ визуально на DT50 ещё не сверял.
**Фаза:** P-FastStart (доводка экранов раздела «Остатки», после P-FS-13/14).

## Задача

Переверстать `StockDetailPage` по присланному макету: белые карточки на светло-сером фоне,
секции «Штрихкоды (N)» и «Наличие по местам хранения»,
закреплённая снизу панель «ИТОГО НА СКЛАДЕ». AppBar не трогать, шрифты — только из проектных
(`Inter` через `RegularTextStyles`/`SemiboldTextStyles`/`BoldTextStyles`).

Доработка по ходу задачи: шапку товара сделать раскрывающимся блоком — наименование видно
всегда, остальные реквизиты скрыты до тапа.

## Критерий готовности

Экран визуально соответствует макету; отвязка ШК (P-FS-12) сохранена; `flutter analyze` без новых
замечаний, тесты и релизная сборка APK зелёные.

## Решения (согласованы с заказчиком)

| Вопрос                                                   | Решение                                                                    |
|----------------------------------------------------------|----------------------------------------------------------------------------|
| Кнопка удаления ШК (в макете её нет)                     | **Оставить крестик справа** в строке ШК, отвязка с подтверждением          |
| Единица у количеств («10 шт» в макете, `uom` = «шт/1кг») | **Без единицы** — только число; единица видна в строке «Ед.» шапки         |
| Вторая строка шапки («ТМ «Фома Лукич»» в макете)         | **Убрать** — выводится только `name` товара                                |
| Изображение товара                                       | **Убрать из карточки** — фотографий в WMS нет, заглушка не нужна           |
| Секция «Штрихкоды»                                       | **Тоже раскрывающаяся**; при отсутствии привязанных ШК не выводится совсем |

Изображение товара из карточки **убрано совсем** (решение по ходу задачи): фотографий в WMS нет
(в выгрузке 1С не приходят), а плашка-заглушка на их месте только занимала высоту. Вернуть —
когда появится источник фото.

## Что сделано

### Раскладка виджетов фичи (по соглашению из [`architecture.md`](../architecture.md))

У фичи `stock` две страницы, поэтому виджеты разложены по назначению:

- `widgets/common/error_retry.dart` — общий для обеих страниц (переиспользован и в карточке);
- `widgets/goods_list/{active_chips,goods_result,stock_filter_button}.dart` — виджеты списка;
- `widgets/stock_detail/**` — новые виджеты карточки.

### Виджеты карточки (`widgets/stock_detail/`)

- **`DetailCard`** — белая скруглённая плашка, базовый «кирпич» всех секций; `padding`
  параметризован (для списка ШК и раскрывающейся шапки передаётся `EdgeInsets.zero`).
  Сделана на `Material`, а не `Container`: внутри есть тапабельные зоны, и ripple должен
  рисоваться поверх белого фона и обрезаться по скруглению.
- **`SectionTitle`** — заголовок секции на сером фоне, вне плашки (остался у «Наличия по
  местам хранения»; у карточки товара и штрихкодов заголовок живёт внутри плашки).
- **`ExpandableCard`** — общий механизм раскрытия: белая плашка, шапка с шевроном видна всегда,
  тело раскрывается тапом по шапке (`AnimatedCrossFade` + `AnimatedRotation`, 200 мс),
  по умолчанию свёрнута. `headerBuilder` получает текущее состояние — так карточка товара
  обрезает длинное наименование только в свёрнутом виде. На нём построены `GoodInfoCard`
  и `BarcodesSection` — анимация, шеврон и зона тапа описаны в одном месте.
- **`GoodInfoCard`** — карточка товара на `ExpandableCard`: наименование видно всегда,
  реквизиты раскрываются тапом. Зачем: на ТСД важнее остатки по ячейкам — в свёрнутом виде
  весь список мест хранения и итог видны без прокрутки. Наименование в свёрнутом виде
  ограничено тремя строками, чтобы длинное имя из 1С не раздувало шапку; в раскрытом —
  показывается целиком. Все реквизиты — единообразными строками «серая подпись + значение
  жирным» (`_InlineProp`).
- **`BarcodesSection`** — «Штрихкоды (N)» на том же `ExpandableCard`: заголовок с количеством
  виден всегда, список раскрывается тапом. Строки — иконка-плашка ШК, код и крестик отвязки
  (диалог подтверждения → `StockDetailCubit.unbindBarcode`). **Если ШК не привязаны, блок не
  выводится совсем** (как и до загрузки карточки): пустая секция на экране ТСД только занимала
  бы место, а число в заголовке до загрузки было бы неверным. Отступ до следующей секции —
  внутри блока, чтобы при скрытом блоке не оставалось двойного зазора.
- **`PlacesSliver`** + **`PlaceTile`** — «Наличие по местам хранения»: булавка, адрес ячейки,
  дата партии, количество зелёным. Здесь же состояния загрузки/ошибки/«пусто».
  **Возвращает sliver, а не обычный виджет:** загрузка, ошибка и «нет остатков» заворачиваются
  в `SliverFillRemaining(hasScrollBody: false)` и центрируются в незанятом остатке вьюпорта.
  Ребёнком `ListView` это недостижимо — вьюпорт даёт детям неограниченную высоту по оси
  прокрутки, и `Center` в такой ситуации сжимается по содержимому (а `Expanded` вне `Flex`
  вообще невалиден).
- **`TotalBar`** — «ИТОГО НА СКЛАДЕ»: закреплена под списком, поэтому итог виден при любой прокрутке.
- **`StockDetailBody`** — прокручиваемая часть (`CustomScrollView`) + закреплённая панель итога.
  `CustomScrollView`, а не `ListView`, именно ради центрирования состояний в `PlacesSliver`.

Страница `stock_detail_page.dart` стала тонкой: DI-провайдер, `Scaffold` (фон `kBg`),
**неизменённый AppBar** и `StockDetailBody`. Добавлен `SystemUiWrapper` (тёмные иконки
статусбара) — шапка светлая, а на «Остатках» статусбар светлый.

### Фикс: клавиатура всплывала при возврате из карточки

На «Остатках» после поиска и захода в карточку товара возврат назад каждый раз поднимал
экранную клавиатуру. Причина не в вёрстке: при `pop` Flutter восстанавливает фокус последнему
сфокусированному полю экрана (`FocusScopeNode.focusedChild`), а вместе с фокусом поля ввода
поднимается и клавиатура. Подтверждено виджет-тестом.

Решение — `core/utils/keyboard.dart` **`dismissKeyboard()`** (`primaryFocus?.unfocus()`;
дефолтный `UnfocusDisposition.scope` заодно очищает `focusedChild` скоупа, иначе фокус вернулся
бы вместе с экраном). Вызывается **перед уходом** с экрана: `GoodsResult.openDetail` (карточка
товара) и `GoodsListPage.openStockEntry` (ввод остатков) — оба выхода с экрана «Остатки».
Клавиатура после этого появляется только по тапу по строке поиска (штатное поведение
`TextField`). Регрессия закрыта тестом `test/core/keyboard_test.dart` (два случая: без вызова
фокус возвращается, с вызовом — нет).

### Строка поиска: крестик очистки

В поле поиска на «Остатках» добавлен суффикс-крестик — виден только при непустом вводе, по тапу
чистит поле и **сразу** сбрасывает запрос. Появился `TextEditingController`; суффикс подписан на
него через `ValueListenableBuilder`, поэтому на каждый символ перерисовывается только иконка,
а не весь экран. В `clearSearch()` отложенный дебаунс гасится: иначе «висящий» таймер применил бы
старый текст уже после очистки. Покрыто `test/features/stock/goods_list_search_test.dart`
(нет текста → крестика нет; ввод → появился и запрос ушёл после дебаунса; тап → поле и запрос
очищены, крестик скрыт).

### Прочее

- `core/utils/date_input.dart` — **`isoToDisplayDate`** (ISO из API → `дд.мм.гггг`); раньше был
  приватный дубль внутри экрана. Количество показывается через существующий `fmtQty`
  (`10.000` → «10»).
- `AppColors`: **`kQtyValue`** (зелёный акцент количества), **`kPlacePin`** (синяя булавка места).
- i18n `stock_detail_screen` перестроена под новую вёрстку: подписи реквизитов отдельными ключами
  (`label_code`/`label_uom`/`label_group`/`label_supplier`), `barcodes_title` с параметром `count`,
  добавлены `places_title`, `batch`, `total_title`; неиспользуемые (`col_cell`/`col_qty`/`total`/
  `error`/`retry`/`barcodes_empty`) убраны.
