# P1-08 · Импорт ячеек через портал (вкладка «Ячейки»)

**Статус:** ✅ код готов, контур зелёный (`flutter analyze` 0 issues, кодогенерация, 28 тестов, web-сборка портала). Визуальная проверка/E2E на живом бэкенде — за пользователем.
**Задача:** сделать на веб-портале рабочую вкладку «Ячейки» (была заглушкой) — загрузку файла ячеек (`.xlsx`, колонки `cell`·`floor`) поверх готового `POST /api/v1/import/cells` (P1-05), по образцу рабочей вкладки «Номенклатура». Только для admin; склад — «Шабулина»/`SHB` (дефолт бэкенда).
**Критерий готовности:** админ на портале во вкладке «Ячейки» выбирает `.xlsx`, загружает и видит отчёт (создано/обновлено ячеек, пропущенные строки); повторная загрузка идемпотентна (без дублей). Вкладка перестаёт быть заглушкой.

---

## Контекст (переопределение задачи)

Исходный объём P1-08 — «кнопка ручного импорта на ТСД» — **снят**: заливать `.xls/.xlsx`-файлы 1С (живут на ПК) через Android-ТСД неудобно, а импорт уже есть на портале. Номер переиспользован под перенос импорта **ячеек** на портал: номенклатура там уже была (P1-09-1), ячейки же грузились только `curl`'ом. Теперь оба справочника — с ПК через портал.

## Что сделано

- **`core/constants/api_constants.dart`** — маршрут `ApiConst.importCells = 'import/cells'`.
- **`portal/data/import_report.dart`** — модель `CellsImportReport` (`warehouse`, `cells_created`, `cells_updated`, `skipped`), переиспользует `SkippedRow`.
- **`portal/data/cells_repository.dart`** — `@lazySingleton CellsRepository.importCells(bytes, filename)` → `POST /import/cells` (multipart, поле `file`) → `Either<Failure, CellsImportReport>`; зеркало `NomenclatureRepository` (маппинг ошибок, 422 → текст с бэкенда).
- **`portal/presentation/tabs/widgets/upload_widgets.dart`** — общие виджеты вынесены из вкладки «Номенклатура» и **переиспользуются обеими** вкладками (DRY): `PortalUploadZone` (параметризован prompt/hint/badge/icon), пунктирная рамка, `PortalStatRow`.
- **`portal/presentation/tabs/nomenclature_tab.dart`** — переведена на общие виджеты (без дублей).
- **`portal/presentation/tabs/cells_tab.dart`** — новая вкладка: выбор `.xlsx` (`pickFileFromBrowser`) → загрузка → карточка отчёта (склад / создано / обновлено / пропущено).
- **`portal/presentation/portal_shell.dart`** — пункт «Ячейки» подключён к `CellsTab` (был `StubTab`).
- **i18n** — блок `portal.cells` (по образцу `portal.nomenclature`).
- **Попутный фикс** (`portal_shell.dart`, `_Header`): убран конфликт `Container` — одновременные `color` + `decoration` (падал портал `Assertion: Cannot provide both a color and a decoration`). На проде не проявлялся — там крутится старый вручную-собранный бандл.

### Ключевые решения

- **Доступ — admin** (эндпоинт `POST /import/cells` admin-only с P1-05; портал и так admin-only). Склад — дефолт бэкенда «Шабулина»/`SHB` (согласован), в UI не выбирается.
- **DRY:** зона загрузки/рамка/строка статистики вынесены в общий `upload_widgets.dart` — обе вкладки импорта используют их; отчётные карточки свои (разные поля goods/cells).
- **Web-only:** выбор файла — `web_file_picker` (js_interop, без плагина), как у номенклатуры.
