# ADHOC-20 (fe) · Поиск принтера на новом ТСД: геолокация выключена

**Статус:** ✅ готово (`flutter analyze` 0 issues, полный прогон 486 тестов зелёный, релизная
APK собирается; **проверено на живом DT50S: с выключенной геолокацией приложение называет
причину и открывает её настройки, после включения принтер находится**).
**Категория:** внеплановая, `adhoc-fe`. Строки в `plan_v3.docx` нет.

## Задача

На новом терминале поиск принтера по Bluetooth сразу падал с сообщением «Поиск не запустился:
нет разрешения или Bluetooth выключен», хотя Bluetooth был включён. На прежнем терминале поиск
работал.

## Критерий готовности

Сообщение называет настоящую причину отказа и подсказывает, как её устранить; после устранения
принтер находится.

## Что сделано

| Файл                                                 | Правка                                          |
|------------------------------------------------------|-------------------------------------------------|
| `android/.../printer/PrinterBridge.kt`                | проверки до поиска, открытие настроек геолокации |
| `lib/core/printer/printer_device.dart`                | отказы `bluetoothOff`, `locationOff`            |
| `lib/core/printer/printer_transport.dart`, `bluetooth_printer_transport.dart` | `openLocationSettings`, разбор кодов |
| `lib/core/printer/printer_service.dart`               | `openLocationSettings`                          |
| `features/debug/.../printer_probe_page.dart`          | кнопка «Настройки» у сообщения о геолокации     |
| `docs/deploy/tsd-setup.md`                            | инструкция по вводу нового ТСД                  |

## Ключевые решения

**Причина — выключенная геолокация.** На новом терминале общий переключатель «Местоположение»
был выключен (`settings get secure location_mode` → `0`). На Android 11 обнаружение
Bluetooth-устройств считается определением местоположения: без включённой геолокации система
не запускает поиск, даже когда Bluetooth включён и разрешение приложению выдано. На прежнем
терминале геолокация была включена, поэтому дефект там не проявлялся.

**Причину называет нативная сторона, до запуска поиска.** `startDiscovery()` отвечает лишь
«не запустился», и прежнее общее сообщение отправляло человека проверять Bluetooth. Теперь до
запуска проверяются Bluetooth (`bluetooth_off`) и, на Android до 12, геолокация
(`location_off`) — у каждой своё сообщение и свой вид отказа. Общее сообщение осталось для
случая, когда система отказала по причине, которую мы не распознали.

**К сообщению о геолокации — кнопка «Настройки».** Она открывает системный экран геолокации:
путь туда проще дать кнопкой, чем объяснять словами.

**Геолокация нужна только для поиска.** Печать на уже спаренный принтер работает без неё,
поэтому приложение требует её только на шаге «Найти». Это записано в инструкцию по вводу
нового ТСД, которой до сих пор не было: она собирает установку, первый вход и подключение
принтера в одно место.

**Проверка на живом DT50S** (геолокация выключена): меню «⋮» → «Принтер» → «Найти» — сообщение
«Включите геолокацию…» с кнопкой «Настройки»; кнопка открывает настройки геолокации; после
включения «Найти» находит принтер.

Пройдено: принтер нашёлся.

## Границы задачи

Поиск принтера есть только на экране наладки, поэтому кнопка «Настройки» — только там.
Печать на спаренный принтер (приёмка, ярлыки) поиска не запускает и геолокации не требует.
