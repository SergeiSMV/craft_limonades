# ADHOC-51 (fe) · ТСД: плитки и действия по правам должности

**Статус:** ✅ завершена (`flutter analyze` чист, весь набор Flutter зелёный; релизная APK и портал
собираются).
**Категория:** внеплановая, `adhoc-fe`. Строки в `plan_v3.docx` нет.

## Задача

После ADHOC-49/50 сервер проверяет на ТСД каждое действие должности, а сам терминал по-прежнему
смотрел на роль: admin видел «Завести пересчёт» и переключатель «маркируемый», остальные — все
плитки. Кладовщик без права на раздел открывал его и получал отказ сервера уже на операции.
Нужно, чтобы ТСД показывал только то, что должности разрешено.

Третья из трёх задач должностей (ADHOC-49 сервер, ADHOC-50 портал); в `main` уходят вместе.

## Критерий готовности

- Плитки главного экрана — по правам: Приход, Перемещение, Задания, Остатки, Проблемы.
- Внутри разделов — действия по правам: виды заданий, «Завести» и «Закрыть» пересчёт, «Ввод
  остатков», признак «маркируемый (ЧЗ)», «Пометить товар» в проблемах.
- Должность без единого права ТСД — вместо плиток «Нет доступа к ТСД».
- Счётчик на плитке «Задания» считает только разрешённые виды.

## Ключевые решения

- **Права — из профиля входа** (`Profile.can`), он хранится на терминале и работает без связи.
  Сервер без должностей прав не отдаёт — тогда по прежней роли.
- **Плитки без права не показываются**, «История» (заглушка) остаётся. Пока профиль не загружен,
  видны все плитки — вход ещё идёт.
- **«Остатки» видны и с одним правом «Ввод остатков»**: вход в него — изнутри «Остатков».
- **Задания фильтруются на терминале по виду**: сервер отдаёт пул целиком, а брать задание без
  права бессмысленно — его операцию сервер отклонит.
- **Без сессии в дереве** (экран в тесте) рабочие действия — разрешены, служебные (пересчёт,
  признак ЧЗ) — нет, как было с ролью.
