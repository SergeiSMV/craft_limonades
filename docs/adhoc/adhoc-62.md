## Задача

Во вкладке «Завершённые» раздела «СБОРКА» касание отгруженного заказа открывало экран отгрузки.
Для отгруженного заказа там была только шапка, «Заказ уже отгружен» и пустые «Короба отгрузки».
Нужна полноценная карточка завершённой сборки: позиции план/факт по партиям, «не хватает», кто
собирал и отгрузил, короба с составом, журнал заказа.

## Критерий готовности

- Касание заказа во «Завершённых» открывает карточку заказа, а не экран отгрузки.
- В карточке:
  - шапка;
  - кто собрал и когда, кто отгрузил и когда;
  - итог «собрано из плана»;
  - позиции: план, партия по плану, собрано всего и по партиям, «не хватает» с количеством;
  - короба «N из M» с составом;
  - история заказа.
- Марки ЧЗ позиции открываются касанием.
- Без права `tsd.picking` карточка не отдаётся (403).

## Ключевые решения

### Данные - те же, что окно деталей портала

Маршрут ТСД `GET /picking/orders/{id}/card` отдаёт ответ окна деталей портала
(`GET /picking/portal/orders/{id}`, P8-03): тот же обработчик и `PickingPortalService.Order`.
Отличается только право - `tsd.picking` вместо прав портала. Карточка только читает.

Статус заказа маршрут не проверяет: на ТСД карточка открывается из «Завершённых», а смотреть
заказы кладовщик сборки и так может.

### Модель на ТСД - своя

Фича ТСД не импортирует домен портала. Свою модель `PickingCard` (freezed + json) она разбирает
из того же JSON.
- **Кто отгрузил** - последнее событие `shipped` журнала: в шапке заказа есть только время
  отгрузки.
- **Состав короба** - пики строк с `state = moved` и номером этого короба. Возвращённые на
  место сервер не отдаёт, поэтому состав совпадает с уехавшим.
- **«Не хватает»** - план минус собрано у живой строки. Отметка «не хватает» без недостачи
  показывается как «Отмечено «не хватает»».

### Экран

Отступы h8, каждый факт своей подписанной строкой. Позиции и короба - выпуклые плашки
`NeumorphicLineTile`.
- Строки шапки:
  - накладная, заказ, клиент, направление, дата накладной, адрес;
  - статус («Отгружен» / «Отгружен частично»);
  - пометки 1С («Удалён в 1С», «Изменён в 1С после отгрузки»);
  - «Собрал:», «Собран:», «Отгрузил:», «Отгружен:»;
  - «Собрано всего: N из M».
- **Позиция:**
  - «План:», «Партия по плану:», «Ячейка реестра:»;
  - «Собрано:» и «Партия ДД.ММ.ГГГГ: N шт» по партиям;
  - «Марок ЧЗ: N».
  - Отметка красным под подписью - «Не хватает: N» или «Убрана реестром» (плашка приглушена).
  - Касание позиции с марками - нижний лист со списком марок.
- **Короб:** «Короб N из M», под ним товар своей строкой и партии с количеством, «Отгружен:».
- **История:** журнал заказа строкой на событие, как «История заказа» портала.

Правки реестра (раздел портала «Правки реестра») на ТСД не показываются: склад они не касаются.
Только со связью: без связи - «Нет связи - карточка заказа открывается только со связью» и
повтор.
