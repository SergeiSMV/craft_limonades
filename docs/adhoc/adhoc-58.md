# ADHOC-58 (be+fe) · ТСД: карточка задания пересчёта — без «приёмки» и «Что разместить»

**Статус:** ✅ завершена (`go test ./...` и весь набор Flutter зелёные, линтеры чисты).
**Категория:** внеплановая, `adhoc-fe` с правкой ответа API (`adhoc-be`). Строки в
`plan_v3.docx` нет.

## Задача

Выполненное задание пересчёта из ленты «Завершённые» открывалось в карточке, написанной под
размещение:

- «Основание: приёмка от 05.11.2026» — приёмки у пересчёта нет, это запасная ветка основания
  с датой создания задания;
- раздел «Что разместить» с пустым списком;
- ни номера пересчёта, ни области, ни хода;
- в «Истории выполнения» только «Создал» и «Выполнено» — кто какие ячейки считал, не видно;
- в самой ленте запись пересчёта шла как «Приёмка без поставщика» и «заходов: 0».

Кнопка «Начать» карточки вела в размещение для любого вида, кроме возврата: открой карточку
незавершённого пересчёта — попадёшь в экран размещения.

## Критерий готовности

- Карточка пересчёта: «Пересчёт: ИН-…», «Область: …», «Подсчитано: N из M ячеек»; раздела
  «Что разместить» нет.
- История пересчёта: «Подсчитал: <кто>» и «Ячейка: <адрес>» на каждую подсчитанную ячейку.
- Запись ленты «Завершённые»: пересчёт, область и ход вместо «приёмки» и «заходов»;
  исполнители — кто считал; фильтр по исполнителю находит пересчёты.
- «Начать» выбирает экран по виду задания; у пересчёта — его список ячеек.

## Ключевые решения

- **Заход пересчёта — подсчитанная ячейка.** Работники берут ячейки, а не задание, поэтому в
  `taskSessionsSQL` добавлены подсчитанные `stocktake_cells` (`counted_by`, `counted_at`). Через
  него же лента считает заходы и исполнителей и работает фильтр по исполнителю — отдельной
  ветки для пересчёта нет.
- **Подсчёт ячейки в журнал задания не пишется.** Факт и так хранится в `stocktake_cells`;
  `Events` вплетает его при чтении (событие `cell_counted`), порядок — по времени, события одной
  транзакции — по `seq`. Второй копии, которая могла бы разойтись с первой, нет.
- **Номер, область и ход** у текущих заданий и в ленте читает один запрос `stocktakeInfoSQL`.
- **«Начать» — явный `switch` по виду задания;** неизвестный вид ничего не открывает, а не
  попадает в размещение по умолчанию.
- Пересчёт целиком не берут, поэтому у его карточки нет «Взять» / «Отказаться» — одна кнопка
  «Начать», открывающая список ячеек (как из «Текущих»).
