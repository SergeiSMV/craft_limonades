# ADHOC-33 (fe) · ТСД: «Остатки» из снимка — товары с остатком, склады, «Номенклатура»

**Статус:** ✅ завершена (`flutter analyze` 0 issues, 637 тестов Flutter зелёные, APK стенда
собирается).
**Категория:** внеплановая, `adhoc-fe`. Строки в `plan_v3.docx` нет.

## Задача

Раздел «Остатки» на ТСД во вкладке «Товары» показывал справочник номенклатуры — все товары,
без количества, в том числе те, которых на складе нет. Остаток был виден только в карточке
товара, а она читала его с сервера (`GET /stock`) и без связи уходила в экран ошибки (долг 22).
Брак, изолятор и возврат поставщику отдельно не посмотреть.

## Критерий готовности

- Вкладка «Товары» — только товары с остатком больше нуля, у строки — общее количество.
- Остаток по внутренним складам — фильтром с множественным выбором, по умолчанию все склады.
- Список и карточка товара работают без связи — по снимку склада с подписью, на когда он.
- Весь справочник товаров (карточка, ШК, привязка ШК) — пункт «Номенклатура» в меню «⋮»
  главного экрана.

## Ключевые решения

### Остаток считается из снимка склада

Снимок (`GET /contents/snapshot`) уже несёт всё: россыпь по ячейкам и живые короба с составом,
у каждой строки — внутренний склад. Остаток товара — сумма россыпи и содержимого коробов,
разложенная по складам; серверу и схеме правки не понадобились. Открытие вкладки и карточки
сначала обновляет снимок: со связью данные на сейчас, без связи — прежний снимок с подписью
«Нет связи — данные на ЧЧ:ММ». Своя неотправленная очередь (приёмка, размещение, перемещение,
пометка брака) накладывается поверх на весь склад сразу, строки с ней — с пометкой «ожидает
отправки». По возврату из карточки список перечитывает снимок, обновлённый карточкой.

### Склады — фильтр, а не вкладки

Складов может быть много, поэтому вкладок по складам нет. В листе фильтров — склады с
множественным выбором, по умолчанию «все»; количество в строке — сумма по выбранным, товар
без остатка на них из списка уходит. Выбранные склады видны чипами под поиском, как группа
и поставщик. Карточка товара показывает все места на всех складах с пометкой склада, итог —
фактическое количество на складе.

### Карточка товара — места с коробом

Строка места — ячейка, короб (код с ярлыка), партия, склад, количество. Порядок — вдоль
стеллажа: по адресу ячейки, в ячейке россыпь раньше коробов, внутри — по партии.

### «Номенклатура» — прежний список справочника

Поиск по справочнику, фильтры по группе и поставщику, скан ШК, предложение привязать
неизвестный ШК — без изменений, только в своём экране из меню «⋮». Обработка поиска и скана
вынесена в общий mixin: в «Остатках» она та же, расходиться копиям незачем. Карточка — общая.

## Границы задачи

- Сервер и схема не менялись; база ТСД — прежняя.
- Отгрузка возврата поставщику (`return_submit`) своей очередью поверх снимка не накладывается —
  как и в карточках ячейки и короба: место товара находит сервер.
