# ADHOC-22 (fe) · «Нет связи» при живой связи: подпись снимка говорит настоящую причину

**Статус:** 🔧 код готов, ждёт проверки на DT50S (`flutter analyze` 0 issues, полный прогон
Flutter-тестов зелёный, релизная APK собирается).
**Категория:** внеплановая, `adhoc-fe`. Строки в `plan_v3.docx` нет.

## Задача

Найдено на DT50S: во вкладке «Короба» после ввода кода и очистки строки поиска над списком
появлялось «Нет связи — данные на ЧЧ:ММ», хотя связь была. То же «нет связи» писалось, когда
поиск уходил в снимок из-за ответа сервера с ошибкой при живой связи.

## Критерий готовности

«Нет связи» пишется только при обрыве связи. Снимок, обновлённый при открытии вкладки, после
очистки поиска показывается без подписи; при ответе сервера с ошибкой — «Данные на ЧЧ:ММ».

## Что сделано

| Файл                                                                  | Правка                                       |
|-----------------------------------------------------------------------|----------------------------------------------|
| `lib/features/contents/domain/contents_entities.dart`                 | `FromSnapshot.offline` — причина: связь или сервер |
| `lib/features/contents/domain/contents_repository.dart`, `data/contents_repository_impl.dart` | список — по исходу последнего обновления снимка; поиск — причина отказа |
| `lib/features/contents/presentation/bloc/boxes_cubit.dart`            | вкладка помнит исход последнего обновления   |
| `lib/features/contents/presentation/widgets/common/freshness_note.dart` | «Нет связи — данные на» / «Данные на»      |
| `test/features/contents/`                                             | очистка поиска, ошибка сервера, подпись      |

## Ключевые решения

**Подпись берётся из исхода последнего обновления снимка, а не из «обновляли ли только что».**
Список коробов всегда читается из снимка; при открытии вкладки снимок сперва обновляется.
Очистка поиска перечитывает тот же снимок без обновления — он от этого не стареет и связь не
пропадает. Раньше перечитывание помечалось как «не только что обновлён», а подпись трактовала
это как «нет связи». Теперь вкладка помнит, чем кончилось последнее обновление, и подпись
следует ему.

**«Нет связи» — только при обрыве связи.** Снимок показывается и когда сервер ответил ошибкой
(сбой, старая версия без нужной ручки, — так ищет поиск по коду с P5-05-1). Связь при этом
есть, и «нет связи» отправило бы кладовщика разбираться с Wi-Fi. Такой снимок подписан
«Данные на ЧЧ:ММ»: что данные не с сервера, по-прежнему видно.

**Проверка на живом DT50S:**

1. Со связью «Остатки» → «Короба»: подписи над списком нет.
2. Ввести код короба, очистить строку: подписи по-прежнему нет.

   подпись та же.
