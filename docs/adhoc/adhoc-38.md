# ADHOC-38 (fe) · Портал: тесты вкладок без браузера — скачивание и выбор файла за развилкой

**Статус:** ✅ завершена (`flutter analyze` 0 issues, 654 теста Flutter зелёные — тест вкладки
документов теперь в их числе; web-бандл портала собирается с браузерной реализацией).
**Категория:** внеплановая, `adhoc-fe`. Строки в `plan_v3.docx` нет; закрывает долг 25.

## Задача

Вкладка документов портала импортирует скачивание файла (`web_download.dart`), а оно тянет
`dart:js_interop` и `package:web`, которые не собираются на VM. Поэтому её тест (закреплённая
панель поиска, ADHOC-26) был помечен `@TestOn('browser')` и шёл только через
`flutter test --platform chrome`. CI гоняет обычный `flutter test` и этот тест пропускал:
регрессия раскладки вкладки прошла бы гейт незамеченной. Тем же путём закрыты обычные тесты
вкладкам «Ячейки» и «Номенклатура» — они импортируют ещё и выбор файла (`web_file_picker.dart`).

## Критерий готовности

Тест вкладки документов идёт в обычном `flutter test` (и в CI); вкладки портала можно
тестировать на VM; браузерная сборка портала работает с прежней реализацией.

## Ключевые решения

### Условный экспорт, а не Chrome в CI

Был вариант добавить в CI шаг `flutter test --platform chrome`. Отказался: нужен Chrome на
раннере, на каждом PR уходят лишние минуты Actions, а покрывался бы только тест, уже
помеченный для браузера. Условный экспорт (`if (dart.library.js_interop)`) — штатный в Dart
способ разделить код по платформам: в браузере подключается настоящая реализация, на VM —
заглушка. Вкладки и их вызовы (`downloadBytes`, `pickFileFromBrowser`) не менялись: они
по-прежнему импортируют `web_download.dart` и `web_file_picker.dart`.

### Заглушка бросает, а не молчит

Портал собирается только для Web, поэтому на VM заглушку видят лишь тесты, которые кнопку
скачивания и диалог выбора не трогают. Вызов на VM бросает `UnsupportedError`: тихая заглушка
выдала бы «скачано» там, где ничего не скачано. В web-бандле портала строк заглушек нет —
проверил по собранному `main.dart.js`.

### Общая модель выбранного файла

`PickedFile` вынесена в свой файл: её используют и браузерная реализация, и заглушка, а
вызывающий код получает её через тот же `web_file_picker.dart`.
