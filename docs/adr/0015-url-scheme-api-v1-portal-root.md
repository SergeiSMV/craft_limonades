# ADR-0015 · Схема URL: портал на корне, API под `/api/v1`

**Статус:** Планируется (P1-09-0)

## Контекст
Появляется веб-портал оператора ([ADR-0012](0012-web-portal-flutter-web.md)), который надо
разместить на том же домене `craft.skogi.ru`, что и API. До сих пор бэкенд отдавал прикладные
роуты с корня (`/auth/*`, `/import/*`), а других клиентов, кроме нативного ТСД-приложения, не было.

Рассматривались три варианта размещения портала:
- **портал под путём** `craft.skogi.ru/portal/`, API остаётся на корне;
- **поддомен** `portal.skogi.ru` → API на `craft.skogi.ru` (кросс-ориджин → нужен CORS);
- **портал на корне** `craft.skogi.ru/`, API переезжает под `/api/v1/`.

## Решение
**Портал занимает корень `craft.skogi.ru/`, API переезжает под `/api/v1/`.**

- Бэкенд: прикладные роуты оборачиваются в `/api/v1` (`/api/v1/auth/*`, `/api/v1/import/*` и всё
  будущее). Инфра-пробы `/health` и `/ready` **остаются на корне** — их дёргает docker-healthcheck
  напрямую к контейнеру, это не часть публичного API.
- ТСД-приложение: меняется только `--dart-define=BASE_URL=https://craft.skogi.ru/api/v1`; пути в
  коде относительные (`dio.baseUrl + '/auth/login'`), правок кода нет — только пересборка APK и
  переустановка на устройство.
- host-nginx: `location /api/ → backend`; `location / → статика портала` (SPA-fallback на
  `index.html`). Конфиг проще прежнего — один префикс `/api/` вместо перечисления путей.

Портал и API — **один origin**, поэтому CORS не нужен и сертификат один.

## Последствия
- **+** Чистый корневой URL для оператора; версионированный неймспейс API (`v1`) даёт запас на
  эволюцию без ломки клиентов.
- **+** Один origin — ни CORS, ни второго сертификата, ни второго vhost.
- **+** nginx-конфиг чище: одна `location /api/`, а не список корневых путей API.
- **−** Ломающее изменение для уже установленного ТСД-приложения: старый APK ходит на корневые
  пути и после переезда перестанет логиниться. Смягчение — переезд делаем **сейчас**, пока это
  один тестовый DT50 и нет реальных данных (в проде дальше — парк устройств, будет дороже).
- **−** Координация деплоя: авто-обновление pull-моделью подтянет новый бэкенд за ~5 мин после
  мержа в `main`; новый APK надо поставить в то же окно, иначе будет провал логина на устройстве.
- Реализация — задача **P1-09-0** (перед порталом P1-09-1, чтобы портал сразу строился на
  конечной схеме URL).
