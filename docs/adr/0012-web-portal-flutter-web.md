# ADR-0012 · Веб-портал оператора на Flutter Web

**Статус:** Планируется (P1-09-1 · P8)

## Контекст
Файлы обмена с 1С (выгрузка номенклатуры, расходные ордера) приходят оператору **на почту, на ПК**.
Единственный клиент WMS до сих пор — Android-приложение, поэтому загрузка файла требовала переноса
`.xls` на устройство: почта → Downloads → file picker. На пилоте это стало бы ежедневным раздражителем.
Ранние редакции плана исключали «веб-оператора» из объёма.

Реализация портала рассматривалась в двух вариантах: серверный рендеринг на Go
(`html/template` + htmx) и Flutter Web.

## Решение
**Портал — отдельное приложение на Flutter Web**, живёт за тем же nginx/TLS, что и API.

Решающий аргумент — **эксплуатационный, а не технический**: проект ведёт один разработчик соло
и сопровождает его годами. Flutter Web даёт один язык на всю систему и переиспользование уже
написанных слоёв ТСД-приложения — моделей, DTO, API-клиента, авторизации и обработки ошибок.
Серверный HTML-стек означал бы второй набор представлений данных и вторую манеру писать UI.

Функции портала: вход по логину/паролю (`/auth/login/password`, P1-01-1), загрузка `.xls`
(номенклатура, ячейки, расходные документы), отчёты импорта, выдача сформированных документов,
список и статусы заданий на сборку.

## Последствия
- **+** Один язык и общие слои с ТСД-приложением; правка модели делается один раз.
- **+** Оператор грузит файл с того же ПК, куда он пришёл — исчезает ручной перенос на устройство.
- **+** Порталу не нужен отдельный рантайм или второй контейнер: статика за существующим nginx.
- **−** Вес бандла на первую загрузку (~2–3 МБ, далее кэш браузера).
- **−** Таблицы, фильтры и выделение/копирование текста в Flutter Web слабее, чем в HTML,
  а портал состоит из таблиц процентов на восемьдесят — UI-возни будет больше, чем кажется.
- Оба минуса приняты осознанно: **оператор работает из офиса на стабильном канале**
  (подтверждено заказчиком). При смене этого условия решение подлежит пересмотру.
- Роль пользователя портала (отдельная `operator` или работа под `admin`) — открытый вопрос №11.
