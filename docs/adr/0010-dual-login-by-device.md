# ADR-0010 · Двойной вход по типу устройства (бейдж vs логин/пароль)

**Статус:** Планируется (бэкенд — P1-01-1, ветвление UI/детект устройства — P2-01)

## Контекст
Кладовщики работают на ТСД и входят сканом бейджа ([ADR-0005](0005-auth-badge-argon2-roles.md)). Но
администраторы/менеджеры управляют пользователями с **обычного Android-смартфона без сканера** — им
нужен нормальный вход по учётным данным.

## Решение
Два пути входа, выбираемые по **типу устройства/роли**:
- **employee на ТСД** — по бейджу (как есть);
- **admin/менеджер со смартфона** — **логин/пароль** (полноценные учётные данные, не производные от
  бейджа).

Тип устройства определяется **по возможности — наличию аппаратного сканера** (сервис сканера /
ScanManager), а не по модели (белый список моделей хрупок). От этого зависит экран входа и способ
ввода ШК. Бэкенд получает отдельную модель учётных данных и режим `/auth/login` для пары логин+пароль
наряду с бейджем.

## Последствия
- **+** Естественный вход для обеих ролей; не тянем сканер-логику на смартфон.
- **+** Детект по возможности работает и на будущих моделях ТСД (не привязан к DT50).
- **−** Расширение auth-контракта бэкенда и модели учёток; ветвление UI входа.
- **−** Открытый вопрос: политика паролей (сложность, сброс, кто заводит учётку) — к реализации.
