# Публикация приложения ТСД в RuStore

Приложение «КЛ: Склад» (`com.craftlimonades.sklad`) публикуется в RuStore публично, издатель -
физическое лицо. Карточка видна всем, но без учётной записи, которую заводит администратор системы,
приложение бесполезно. Приложение стенда («КЛ: Склад · СТЕНД», `…sklad.stand`) в RuStore не
публикуется. Решения и проверка - в [ADHOC-66](../adhoc/adhoc-66.md).

Иконка карточки - [`rustore-icon-512.png`](rustore-icon-512.png): 512×512, фон по всей площади,
та же картинка, что на терминале (фон и передний план адаптивной иконки).

## Сборка версии

1. Поднять версию в `apps/craft_wms/pubspec.yaml` (`version: X.Y.Z+N`): `N` (versionCode) каждый раз
   больше прежнего, иначе RuStore не примет файл.
2. Из корня репозитория: `bash scripts/build_tsd_rustore.sh`. Скрипт собирает релиз под ARM, падает,
   если нет ключа приложения или APK подписан отладочным ключом, и печатает отпечаток подписи, пакет,
   версию и разрешения.
3. Файл для загрузки - `apps/craft_wms/build/app/outputs/flutter-apk/app-release.apk`.

**Ключ приложения.** Версии в RuStore принимаются только с той же подписью, что у первой. Ключ лежит
вне репозитория, путь и пароли - в `apps/craft_wms/android/key.properties` (в `.gitignore`).
Резервная копия ключа и `key.properties` хранится отдельно от рабочей машины. Потеря ключа - смена
подписи через поддержку RuStore (support@rustore.ru), все версии уходят в архив.

Отпечаток сертификата (SHA-256):
`33:79:79:C8:92:29:2A:14:48:77:F7:60:0F:E6:92:8D:ED:38:B4:F5:87:82:E4:2B:CE:73:9F:67:0A:5D:D7:99`.

## Первая публикация - что заполняется в RuStore Консоли

1. **Версии → Загрузить** - `app-release.apk`. Раздел «Подпись приложения» нужен только для AAB,
   для APK не заполняется.
2. **Информация о приложении** - тексты ниже, иконка `rustore-icon-512.png`, скриншоты (не меньше трёх,
   вертикальные, PNG/JPG до 3 МБ; витрина приводит их к 9:16 - проверить предпросмотр в Консоли).
3. **Безопасность данных** - декларация ниже.
4. **Способы связи** - e-mail из политики конфиденциальности.
5. **Комментарий модератору** - текст ниже: вход через «Демо-режим».
6. **Отправить на модерацию.**

Модератор работает на демо-сервере (ADHOC-67), а не на проде: кнопка «Демо-режим» на экране входа
переключает приложение на выдуманный склад и пускает без пароля с полными правами. Учётная запись
на проде для модерации не нужна. Демо-сервер должен быть поднят до отправки (`craft.sh`, пункт 20),
а APK - собран с адресом демо (`build_tsd_rustore.sh` подставляет его сам). Данные демо сбрасываются
каждую ночь в 03:00 МСК.

## Тексты карточки

**Название** (не больше 30 символов, совпадает с подписью под иконкой): `КЛ: Склад`

**Категория:** Бизнес. **Возраст:** 0+. **Теги:** склад, WMS, ТСД, учёт товара, инвентаризация.

**Краткое описание** (не больше 80 символов):

> Складской учёт на терминале сбора данных: приёмка, размещение, сборка, остатки.

**Полное описание:**

> «КЛ: Склад» - рабочее приложение системы управления складом (WMS) для сотрудников склада. Работает
> на терминалах сбора данных со встроенным сканером штрихкодов (Urovo DT50S и аналоги на Android 11
> и новее).
>
> Что умеет:
> - вход по бейджу сотрудника или по логину и паролю;
> - приёмка товара от поставщика с печатью ярлыков коробов на Bluetooth-принтере;
> - размещение по ячейкам склада и перемещение между ячейками;
> - остатки по ячейкам, партиям и коробам;
> - сборка заказов покупателей по реестру из учётной системы и отгрузка коробов;
> - пересчёт (инвентаризация) ячеек;
> - отметка проблем с товаром с фотографией: бой, порча, просрочка;
> - работа с марками «Честного знака»;
> - работа без связи: операции копятся на терминале и уходят на сервер, когда связь появляется.
>
> Учётные записи заводит администратор системы склада. Самостоятельной регистрации нет.

**Что нового** (для следующих версий - конкретные изменения, не «стало лучше»).

## Безопасность данных - декларация

| Данные                       | Собираются | Зачем                                   |
|------------------------------|------------|-----------------------------------------|
| ФИО, логин                   | да         | вход и права доступа                    |
| Действия в приложении        | да         | складской учёт (журнал операций)        |
| Фото                         | да         | фото повреждённого товара к проблеме    |
| Диагностика (ошибки)         | да         | исправление ошибок приложения           |
| Местоположение               | нет        | -                                       |

Данные передаются только на сервер системы склада по HTTPS, третьим лицам не передаются, рекламы нет.

**Обоснование чувствительного разрешения `ACCESS_FINE_LOCATION`:**

> Разрешение объявлено только для Android 11 и ниже (maxSdkVersion 30): на этих версиях Android не
> выдаёт результаты поиска Bluetooth-устройств без доступа к местоположению. Приложение ищет
> Bluetooth-принтер этикеток; координаты не запрашиваются, не хранятся и не передаются. На Android 12
> и новее используется BLUETOOTH_SCAN с флагом neverForLocation.

## Комментарий модератору

> Приложение - рабочий инструмент складских сотрудников (WMS) для терминалов сбора данных со
> сканером. Учётные записи заводит администратор, регистрации в приложении нет. Для проверки
> на экране входа нажмите «Демо-режим», затем «Войти в демо»: откроется демонстрационный склад с
> выдуманными товарами, вход без пароля, доступны все разделы. Данные демо возвращаются к исходным
> каждую ночь. Вернуться к обычному входу - «Вернуться к рабочему серверу» на экране входа. Сканирование штрихкодов
> работает только на терминалах со встроенным сканером, на обычном телефоне доступен просмотр
> разделов. Марки «Честного знака» в демо не читаются - приложение прямо сообщает об этом. Товарный знак «Крафтовые лимонады» на иконке и заставке принадлежит
> компании-работодателю, для которой разработана система.
