# Ввод нового ТСД

Как подготовить новый терминал Urovo DT50S к работе: установить приложение, войти, подключить
принтер этикеток. Делается один раз на терминал. Стек и сборка — в [dev-deploy.md](dev-deploy.md).

## Что нужно

- Терминал Urovo DT50S (Android 11) и USB-кабель.
- Машина разработчика с Flutter и Android SDK, файл `apps/craft_wms/.env` с адресом прода.
- Wi-Fi склада: первый запуск — обязательно со связью.
- Принтер этикеток Xprinter XP-P323B, заряженный, с рулоном 58 × 40 мм.

## 1. Разрешить установку по USB

На терминале: «Настройки» → «О телефоне» → семь раз нажать «Номер сборки» — откроется раздел
«Для разработчиков». В нём включить «Отладка по USB». Подключить кабель и на запрос
«Разрешить отладку по USB?» ответить «Разрешить».

```bash
alias adb=~/Library/Android/sdk/platform-tools/adb
adb devices          # терминал в списке со статусом device (не unauthorized)
```

## 2. Установить приложение

Только **релизной** сборкой, не `flutter run`: на терминал ставится то же, что работает
на складе.

```bash
cd apps/craft_wms
flutter build apk --release -t lib/main.dart --dart-define-from-file=.env
adb install -r build/app/outputs/flutter-apk/app-release.apk
```

Если к машине подключено несколько терминалов, указать нужный: `adb -s <серийный> install …`
(серийный — из `adb devices`).

## 3. Первый запуск — со связью

Включить Wi-Fi склада, открыть «КЛ: Склад», войти бейджем. Дождаться обновления справочников
(значок в шапке главного экрана).

Первый вход без связи не сработает и не должен: вход без связи разрешён, только если терминал
выходил на связь с сервером не дольше суток назад, а у новой установки такой отметки нет.

Режим вывода сканера менять не нужно: приложение принимает сканы и в режиме «клавиатуры»,
и в intent-режиме.

## 4. Подключить принтер

1. **Включить Bluetooth и геолокацию** («Местоположение») в шторке терминала.

   ⚠ Геолокация обязательна для **поиска** принтера: на Android 11 система не ищет
   Bluetooth-устройства с выключенной геолокацией, даже если Bluetooth включён и разрешение
   приложению выдано. Без неё приложение скажет «Включите геолокацию…» и предложит кнопку
   «Настройки».
2. Включить принтер.
3. В приложении: главный экран → меню «⋮» → «Принтер» → «Найти». Выбрать XP-P323B
   из найденных и подтвердить спаривание. Принтер бывает виден в эфире дважды, под адресами,
   различающимися одним символом (`DC:…` и `DD:…`): печатает только классический Bluetooth,
   адрес `DC:…`.
4. Задать размер рулона 58 × 40 мм, промежуток 2 мм, и нажать «Калибровка» — принтер прогонит
   пару этикеток, это измерение, а не брак.
5. Нажать «Ярлык ГЕ» — напечатается ярлык с пометкой «ПРОБНАЯ». QR стоит по центру, под ним
   короткий код.

Рулон заправлять **с ограничителем по ширине**: головка шире рулона (72 мм против 58), и при
свободной заправке печать уезжает с наклейки.

**После спаривания геолокацию можно выключить:** печать на уже спаренный принтер работает
без неё. Включать снова — только чтобы найти другой принтер.

## 5. Проверить

- Главный экран открывается, плитка «Задания» показывает число текущих заданий.
- «Остатки» → скан штрихкода товара открывает карточку товара.
- Печать ярлыка из приёмки или с экрана наладки проходит.
