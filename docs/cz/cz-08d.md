# CZ-08D · Сценарные тесты Честного знака и документация

**Статус:** ✅ готово (`go test ./...` и `golangci-lint` чисты). Код приложения не менялся,
миграций нет, Flutter не затронут.
**Категория:** плановая, фаза CZ, завершающая задача фазы.
**Процесс:** [`chestny-znak.md`](../chestny-znak.md).

## Задача

Проверить путь марки целиком по живой базе: приёмка агрегата и россыпи, вскрытие, отгрузка и
выгрузка для УПД. Шаги покрыты тестами CZ-03…CZ-07, но не их стык. Описать работу с ЧЗ одним
документом `docs/chestny-znak.md`.

## Критерий готовности

- Сценарий целого короба: приёмка короба ЧЗ и россыпи, размещение, сборка коробом и маркой,
  отгрузка без вскрытия, в УПД - код агрегации с марками и марка россыпи.
- Сценарий вскрытого короба: перемещение вынимает марку, короб вскрыт, упаковка цела, в УПД -
  упаковка своим кодом.
- Сценарий частично взятого короба: вскрытие на «Завершить сборку», УПД марками.
- `docs/chestny-znak.md` - граница, коды, хранение, путь марки, УПД, ссылки на сценарии.

## Ключевые решения

### Уровень сервисов, операции очереди

Стенд `czEnv` - стенд сборки P9-09D (`pickEnv`) с ячейкой приёмки, поставщиком и маркируемой
водой. Приёмка, размещение, перемещение и пик идут через `OperationsService.Apply` - тем же
разбором тела, что операции ТСД; реестр - настоящим `.xlsx`, отгрузка и выгрузка - сервисами
сборки и портала. Чтения True API в сценариях нет: на приёмке данные ЧЗ уже прочитаны ТСД
(CZ-05), сервер принимает их телом операции.

Итог проверяется в базе и в файле: место и статус каждой марки, вскрытые упаковки, строки листа
«Марки для УПД».

### Сценарии

- **`TestCZScenario_wholeBoxShipped`** - короб ЧЗ (групповая упаковка с марками 1-2 и марка 3)
  в A-1, марки 4-5 россыпью в ячейку приёмки; вода стала маркируемой. Россыпь размещена марками
  в B-1. Заказ 15601 - коробом ЧЗ, 15602 - маркой 4. После отгрузки ничего не вскрыто, марки 1-4
  отгружены, 5 в B-1. УПД: код короба, марки 1-3 «в коробе ЧЗ», марка 4.
- **`TestCZScenario_openedBox`** - марка 3 перемещена из короба в B-1: вскрыт короб, упаковка
  цела. Заказ 15601 - упаковкой (марки 1-2) из короба и маркой 3 из B-1. УПД: код упаковки,
  марки 1-2 «в упаковке ЧЗ», марка 3; кода короба нет.
- **`TestCZScenario_partialBox`** - заказ на 2: марки 1 и 3 из короба. В сборке короб цел, марки в
  ГЕ. После «Завершить сборку» вскрыты короб и упаковка, марка 2 осталась в коробе ЧЗ. УПД
  собранного заказа - марки 1 и 3.
