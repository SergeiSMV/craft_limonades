# CZ-01 · Разведка: КриптоПро на сервере, токен True API, проверка данных

**Статус:** ✅ завершена (токен получен на проде, марки и агрегаты прочитаны, ответы — в
ADR-0017; часть проверок осталась — в границах задачи).

## Задача

До кода проверить на живых данных, что WMS может читать Честный знак: получить токен True API
подписью КЭП сотрудника с МЧД при роли «без права подписи», прочитать реальные марки и коды
агрегации, проверить, что отдаёт сканер DT50S.

## Критерий готовности

Токен получен, статус реальной марки прочитан, ответы на проверки записаны в ADR.

Код приложения не менялся.

Порядок:

1. Установил на сервер службу смарт-карт (`pcscd`, `libccid`) и КриптоПро CSP 5.0 R3 для
   Linux (deb, x64) с поддержкой считывателей, Рутокена и CAdES; лицензия — пробная на 90 дней.
2. Нашёл на Рутокене контейнер сотрудника и поставил его сертификат в личное хранилище
   пользователя сервера со ссылкой на ключ.
3. `token.sh`: `GET /auth/key` → присоединённая подпись CAdES-BES (`cryptcp`, PIN вводит
   владелец ключа) → `POST /auth/simpleSignIn` — токен получен (`HTTP 200`). Токен — на
   организацию по МЧД, с товарными группами участника.
4. Снял коды с DT50S (экран «Сканер», текст экрана — через `adb`) и прочитал их `info.sh`
   (`POST /cises/info`): марку пива, транспортный короб (SSCC), групповые упаковки
   безалкогольного пива и лимонада и бутылку из упаковки лимонада.

## Ключевые решения

Записаны в ADR-0017. Кратко:

- **Токен — на организацию** по МЧД, роли «без права подписи» достаточно для чтения; марки
  читаются только по товарным группам участника (у воды — `403`).
- **Марка — по КИ**, части до GS; с криптохвостом True API её не находит. DT50S отдаёт GS.
- **Два вида агрегата:** транспортный — GS1-128, код `00`+SSCC; групповой — DataMatrix того же
  вида, что марка единицы, со своим GTIN. Состав — одним запросом, у вложенной марки — `parent`.
- **Партия — дата производства единицы:** у групповой упаковки дата — момент агрегации.
- **Марка уникальна:** на размещении её привязывают к ячейке, россыпь можно собрать в свой
  короб с QR — внутренний код агрегации склада, в ЧЗ он не регистрируется.

## Проверка

На сервере, где вставлен токен и стоит КриптоПро:

```bash
cd scripts/cz-probe
CZ_THUMB=<SHA1-отпечаток сертификата> ./token.sh
./info.sh '<КИ марки>' '00<SSCC>'
rm -f .token
```

Ожидаемо: «Токен получен (HTTP 200)», по марке и агрегату — `HTTP 200` с данными продукции
и составом. Токен после проверки удалить.
