# Фаза P1 — справочники, остатки, импорт, веб-портал

Задачи фазы: вход по логину и паролю для admin, схема справочников, партии и остатки,
атомарные движения остатка, импорт номенклатуры и ячеек, read-API, экраны ТСД, портал.

Файлы `p1-dN` — вставные задачи по деплою и эксплуатации, инициированные по ходу работы.
В плане их нет; они предшественники серии `ADHOC-*` (см. [../adhoc/](../adhoc/)).
