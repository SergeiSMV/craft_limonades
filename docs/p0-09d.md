## Решения по оформлению

- **Диаграммы — mermaid** (не картинки): рендерятся на GitHub, правятся как текст, версионируются в git.
- **ADR — по одному файлу на решение** + реестр; статусы «Принято / Планируется / Заменено».
- **Ссылочность:** `architecture.md` и `deploy.md` ссылаются на релевантные ADR; README проекта — на `deploy.md`.
